# Highlander

There can be only one. Enter your name to claim the hill — the longer you hold it, the higher you rank.

## Features

- **Live timer** — see exactly how long the current name has held the hill
- **Real-time leaderboard** — top 5 all-time reigns, updated instantly across all users
- **Recent reigns** — toggle between 7-day and 30-day leaderboards
- **Profanity filter** — names are checked before submission
- **Input validation** — no empty names, 15-character max

## Tech Stack

- **React** + **Vite**
- **Firebase Firestore** — real-time database and hosting

## Getting Started

```bash
npm install
npm start
```
